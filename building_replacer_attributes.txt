cvs_icarus_level_limit - If buildings are above the max level cap allowed to the user, they will destroyed on resupply. I HIGHLY recommend not turning this off, but you may.
cvs_enforce_level_limit - True/False. (True by default) Whether or not buildings should lower their max level in accordance with the user.
cvs_lax_level_limit - True/False. (True by default) Whether or not buildings should raise their max level in accordance with the user.
cvs_enforce_health_limit - True/False. (True by default) Whether or not buildings should lower their max health in accordance with the user.
cvs_enforce_health_limit_upgrade - True/False. (True by default) If cvs_enforce_health_limit is false, should it still change upon upgrading?
cvs_lax_health_limit - True/False. (False by default) Whether or not buildings should raise their max health in accordance with the user.
cvs_lax_health_limit_upgrade - True/False. (True by default) If cvs_lax_health_limit is false, should it still change upon upgrading?

// The bread and butter.
// Blueprint is the blueprint placing model, construction is the model used during construction, and "model" is just the model used for regular operation
// Blueprints do need to be manually defined per level, sorry. I know there are litterally no blueprints currently existing beyond level 1 but I wanted support anyways.
"{buildingtype} level {level} upgrade cost"
// Modify the amount of metal is takes to upgrade from this level by this much.
"{buildingtype} scale"
// Scale this building type's model by this much.
"{buildingtype} BBox"
// Define this building ypes BBox (ex: "{buildingtype} BBox" "-20 -20 0 20 20 125")
"engy mini {buildingtype}"
// Your buildings of this type are "mini" buildings. (Smaller gibs, can't be upgraded, sentries get their iconic model and stats)
"{buildingtype} max level"
// Your buildings of this type have their levels change by this amount, can be positive to increase the max level of buildings that are normally locked to level 1
// In the future I'll add level 4 and beyond support if I ever can, but it doesn't seem to be doable rn...
"{buildingtype} health mult"
// Multiplies this building type's health by this amount
"{buildingtype} level {level} health mult"
// Multiplies this building type's health at this level by this amount
"{buildingtype} compatability"
// If the compatability of the user is ever different from the compatability from when the building was built, it will be destroyed.
"{buildingtype} think script"
// Think script to be attached to the building.
"{buildingtype} setup script"
// Script that is run as soon as the building is created (NOTE: This is while it is still a blueprint!)
"engy sentry bullets mult"
// Multiplier to how many bullets a sentry should fire per shot.
// Does not work on projectiles.
"engy sentry wrangle dmgtaken"
// How much more/less damage a sentry should take while wrangled.
"engy sentry wrangle firerate"
// How much faster/slower a sentry should fire while wrangled. Only works for sentries which fire bullets.
"engy sentry spread"
// The vector that a sentry's bullet shots should spread in (ex: "engy sentry spread"		"0.125 0.125 0.125")
"engy sentry spread mult levels"
// How much the spread of the vectors should be multiplied per level (ex: "engy sentry spread mult levels"	"1 0.8 0.6")
"engy sentry wrangle spread mult levels"
// How much the spread of the vectors should be multiplied per level while wrangled (ex: "engy sentry wrangle spread mult levels"	"1.2 1.2 1.1")
"engy sentry fire rate levels"
// How much the firing spread of the sentry should be multiplied per level, only works on sentries that fire bullets ftm. (ex: "engy sentry fire rate levels"	"1 1.334 1")
"engy sentry cond"
// Condition to apply to an enemy hit by the sentry, seperated by levels (ex: "engy sentry cond"		"27 1 27 2 27 3")
"engy sentry self cond"
// Condition to apply to yourself uppon hitting and enemy with your sentry, seperated by levels (ex: "engy sentry self cond"		"11 1 11 2 11 3")
"engy sentry burstfire"
// Burstfire for the sentry, Only works for sentries which fire bullets. (ex: "engy sentry burstfire"		"3 2.5")
"engy sentry limited range"
// Bullets from this sentry are limited to this distance in hammer units.
"engy sentry heal per hit"
// The sentrygun heals itself for this much upon hiting an enemy
"engy sentry upgrade per hit"
// The sentrygun upgrades itself for this much upon hiting an enemy
"engy sentry bullet flags"
// Change the bullets flags on the sentry's bullets. (only important ones are 1 for a single perfect accurate bullets per shot and 2 for not being able to shoot into water.)
"engy sentry bullet tracer frequency mult"
// Compared to 1.
"engy sentry bullet damage type"
// Change the damage type of the bullets this sentry fires.
"engy sentry nonbullet damage type"
// Change the damage tpye of the non-bullets this sentry fires.
"engy sentry MOOF"
// Accelerate projectiles fired by this sentry by this amount.
"engy sentry proj spread"
// The vector that a sentry's projectile shots should spread in (ex: "engy sentry proj spread"		"0.125 0.125 0.125")
"engy sentry bullet damage levels"
// Modifies much damage bullets from this sentry deal per level (ex: "engy sentry bullet damage levels"	"0.175 0.2 0.225")
"engy sentry nonbullet damage levels"
// Modifies much damage non-bullets from this sentry deal per level (ex: "engy sentry nonbullet damage levels" "0.8 0.8 0.8")
"engy dispenser range levels"
// Modifies dispenser range per level (ONLY WORKS ON ONE DISPENSER AT A TIME!!!)
"engy dispenser rate levels"
// Modifies dispenser rate per level (ONLY WORKS ON ONE DISPENSER AT A TIME!!!)

"extra dispensers"
