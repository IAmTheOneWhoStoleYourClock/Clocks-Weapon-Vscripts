"custom aura cond"

"custom aura player attrib"
// What attribute should be applied to players in the radius?
// Input as 'atrribname' value (ex: "custom aura player attrib"	"'max health additive bonus' 100")
"custom aura weapon attrib"
// What attribute should be applied to all of the weapons of players in the radius?
// Input as 'atrribname' value (ex: "custom aura player attrib"	"'damage bonus' 1.2")
"custom aura heal"
// How much should the aura heal?
"custom aura heal time"
// How often should the aura heal? (Note that the aura is only checked once every 0.5 seconds,
// so anything below that is ineffective and values not evenly divisible by 0.5 may be unevenly applied.)
"custom aura affect self"
// Makes the aura effect the user as well.
