"has charge"
// Gives you a charge depending on this list:
// "regular" - Regular charge you've come to know and maybe come to love
// "leap" - Leap upwards in the direction you are looking!
// "leap_omni" - same as leap, but you can also leap downwards while airborne. If you want that for some reason.
// "leap_charge" - Leap and charge.
// "leap_omni_charge" - Omni leap and charge.
// "gravdash" - Charge directly in the direction you are facing, no change in course once you've begun!
// "gravdash_charge" - Gravdash and charge.
// "gravdash_hold" - Gravdash, but it ends when you let go of secondary attack.
// "jetdash" - Charge directly in the direction you are facing, but this time you can change course as you wish!
// "jetdash_charge" - Jetdash and charge.
// "jetdash_hold" - Jetdash, but it ends when you let go of secondary attack.
// "skywards" - Flings you straight up into the air
// "skywards_charge" - Skywards and charge.
// "display" - No effect, just for if you want the charge meter active.
// Add "_active" to the end to make it only occour while the weapon is active.
// Do not mix multiple weapons that have this together, I don't have that accounted for.
// Works on all weapons except shields.
"charge cost"
// Mutiply the cost of charging (100%) by this much.
"charge delay"
// users must wait this amount in seconds after charging to be allowed to charge again.
"charge slam"
// Slam into the ground with anchor stats upon finishing a charge. (no effect on leaps)
"charge explode"
// Explode upon finishing a charge. (no effect on leaps)
"charge speed increased"
"charge speed decreased"
// Increases or deacreases the speed of a charge by this much (also works on leaps and alt-charges)
// For regular charges this caps at demo's normal charge speed (750 HU/s), at least for the time being.
"charge cond"
// Apply this condition while charging. (no effect on leaps)
